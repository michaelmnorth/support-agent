# Reply templates

Each `*.txt` here overrides the built-in default of the same name. Delete a file to fall back to the default.

| File | Used when |
|------|-----------|
| `propose_email.txt` | Offering times by email |
| `propose_slack.txt` | Offering times in Slack |
| `propose_teams.txt` | Offering times in a Teams chat |
| `confirm_email.txt` / `confirm_slack.txt` / `confirm_teams.txt` | The other side picked a time |
| `none_available.txt` | No slot satisfies the rules |
| `owner_ping.txt` | The message sent to *you* for one-click approval |

Placeholders: `{first_name}` `{owner_first}` `{options}` `{client_zone}` `{owner_zone}` `{duration}` `{topic}` `{bullet}` `{signoff}` `{chosen}` `{teams_note}` `{requester}` `{channel}`.

Paste two or three real replies you have sent into `propose_email.txt` style and the skill will match your voice. The time lines in `{options}` are generated by code, so they are always converted correctly.
